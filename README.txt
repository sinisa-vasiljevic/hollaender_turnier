Holländer-Turnier PWA - Version 1.0.0

1. ZIP entpacken.
2. Dateien auf einen HTTPS-Webspace oder GitHub Pages laden.
3. index.html im Browser öffnen.
4. Auf dem iPhone in Safari: Teilen > Zum Home-Bildschirm.

Hinweis: Ein Service Worker funktioniert über HTTPS oder localhost, nicht zuverlässig per direktem file://-Aufruf.
